2.1 Définitions

Lot
Fichier CSV livré en une fois, avec une ligne d’en-tête. Les lignes sont numérotées comme dans le fichier : l’en-tête est la ligne 1.
Écart bloquant
Règle non respectée qui refuse le lot : champ absent, en-tête dupliqué, valeur sans en-tête, valeur obligatoire invalide, clé en double ou lot vide.
Écart à revoir
Différence qui n’empêche pas de lire le lot mais demande l’avis du responsable du contrat, par exemple une colonne non prévue.
Quarantaine
État d’un lot refusé : aucun consommateur déclaré n’en reçoit la version.
Empreinte
Condensé SHA-256. Celle du contrat désigne la version exacte évaluée, celle du lot le fichier exact contrôlé.
